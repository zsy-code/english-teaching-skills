# 课文教学方案

先核对完整原文与结构，确定学生读完应理解的主要内容和信息关系。开场交代这篇文章讲什么、这次重点读懂什么，再进入原文。

依据文体和内容组织讲解：对话关注谁在回应谁、目的和话题怎样推进；叙事关注事件与因果；介绍、说明或邮件关注主题、段落分工和信息联系。用原文证据支持解释，把创作者推测与原文事实分开。

让学生接触完整原文，可完整呈现并分段朗读，不必先整篇读完再逐段重读。重点解释影响整篇理解的词句、指代、衔接和表达；其余内容通过朗读与简短释义串联，不把每个词句都拆成独立课程。

画面随文本组织信息，如人物对话、事件顺序或位置关系；不为图示补造原文未交代的关系。补充情境应与原文区分。

理解过程中保留一处值得学生回到原文思考的练习，题目和反馈指出依据。较长课文若有不同的重要理解目标，可增加必要检查，不逐段强制设题。结尾串回整篇内容，可结合原文线索作简短复述或表达，不硬加道德结论。

交付篇目来源与完整性说明、教学目标、按播放顺序组织的分段场景和基础台词、关键原文位置、题目与反馈。方案中说明哪些内容重点讲、其余原文如何串联，但不估算时长或改写原文代替原文。
