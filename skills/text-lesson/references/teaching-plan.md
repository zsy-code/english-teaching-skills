# 课文教学方案

目标是理解全文主要内容与组织关系，并借助记忆线索复述、逐步按原文背诵。复述重在内容与关系，背诵需要恢复原文措辞；听过或选对答案不等于记住。

先核对完整原文、段落和说话人，概括主旨，按意思划分部分并标明原文对应。结构由文章决定，可用事件发展、对话推进、空间路线或主题分支；不按句拆分，不给并列内容强加因果。缺少上下文时保留未知。方案需规划完整结构，但学生看到的大纲随讲解逐步形成。

## 课程推进

1. 主题引入与全文预览：用主题画面和简短引入说明读什么，展示原文并完整听读一次，先建立整体印象。短文完整呈现，长文按原文顺序分屏；不提前展示分部结论或完整大纲，不堆译文与分析标注。
2. 分部理解：每次围绕一个完整意思读原文，讲清内容、细节关系及前后联系。画面表达当前内容中的人物、动作及关键关系，建立之后可用于回忆的视觉线索；不能只用同主题的装饰图。只解释妨碍理解或记忆的词句，不逐句翻译后罗列语言点。
3. 随讲随归纳：理解当前部分后，用标题、关键词或图像归纳并加入大纲，再衔接下一部分。大纲只保留已学内容，未学部分不提前出现。局部回忆安排在有完整内容可回忆的位置，不要求每部分都做题或暂停。
4. 串起全文：全文讲完后，以图文回顾表呈现完整结构，每行对应一个意义单元，将前面讲过的画面与对应原文放在一起。原句内高亮承载主要内容或组织关系的少量关键词，帮助从画面找回原文，不再完整重讲一次。长文按原文顺序分屏，不缩小字号硬塞一页。
5. 复述与背诵：沿用回顾表的图文对应，先隐藏原句、保留画面与关键词尝试复述，再按需要减少关键词或提供句首、连接词支持背诵；核对时恢复原句。不要旁白刚给完答案就宣称学生完成回忆。
6. 复习收束：最终画面保留覆盖全文各部分及其关系的图文提纲；它与分屏展示的详细原句表各有用途，不以其中一屏代替全文。简短说明怎样继续练习。

将以上过程组织成一条正常播放即可走完的路线。说明讲过的内容如何留下记忆线索、后续何时复用，以及回顾和练习分别覆盖哪些原文部分。分屏由时间线按内容顺序推进，不靠学生操作补齐课程；正文不设计按钮或导航，暂停、回放及已支持的练习交给统一播放器。不要为展示不同提示方式，让同一批内容反复从头切换。

学生用现有暂停与回放自主练习，操作提示在首次需要时说明，不为模拟互动添加长静音；不承诺未实现的录音评分或自动背诵判定。选择题只用于确有必要的理解难点，不能代替复述与背诵。

方案交付：学习目标；全文结构与原文对应；按播放顺序的场景和基础台词；大纲逐步形成的过程；图文回顾表的内容分组、画面线索及撤句与核对方式。说明复述与背诵范围，不估算时长。用户确认后再细化逐句脚本。
