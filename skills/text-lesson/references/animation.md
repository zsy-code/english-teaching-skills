# 动画制作与固定播放器

输入：用户已确认的当前联合脚本、真实配音、timing.json、用户可用的视觉参考。输出：原创课程画面、可拖动的 HTML 课程包和实际检查记录。此阶段不修改已确认教学范围，不新增强制审批。

## 画面制作

读取运行环境中的 HyperFrames 入口 skill，并按其路由读取所需的创意、动画、结构与 CLI 规范。它负责画面实现；本 skill 负责教学内容、配音及课程交付。缺少依赖时保留现有材料并说明，安装另行处理。

先根据本课主线写简短 design.md：确定哪些对象贯穿故事、各段焦点、文字与图解的关系、必要动作和空间安排。涉及重点切换的片段，在同一份 design.md 中列出“台词锚点 → 当前焦点 → 保留/退出内容 → 下一状态”；据此实现整组切换，不把 cues 当作逐项添加元素的清单。让同一教学动作中的人物、道具和标签有共同的位置依据，并列文字共享基线；版面按本段内容决定，不使用固定内容排版模板。不要将审查报告、抽象口号或旧例子的特殊规则塞进制作提示词。

课文开场呈现主题与全文预览，随后聚焦当前部分；归纳时逐步加入已学提纲，全文讲完才展示完整大纲。局部与提纲复用关键词和视觉对应，不再附加重复目录。回忆时检查正文、字幕和旁白都没有提前给出答案，核对时再恢复对应原句。

按元素的实际变化选择素材：静态内容可用生成图片，需要形变、肢体动作或部件联动的内容使用 SVG 等可控图形；文字与标注由代码叠加。同一画面允许混合，不按整页或整课统一限定，也不规定图片数量。仅有入场、平移、缩放或淡入淡出，不构成必须使用 SVG 的理由。需要连续动作的部件预先分层，不将整张静态人物图平移当作肢体动作。静态图片按 [服务选择](services.md) 优先调用当前框架的内置图片生成工具，按需读取相应图片 skill。

需要保持场景、角色或道具一致时，将已选定的图片实际传入模型的 reference 输入，或使用图片编辑能力在原图上修改；保留不变部分，只改变本镜头需要的内容。不要仅重复文字描述后逐张独立生成。先复用已有素材，确需新视角或新状态时再生成，并核对外观、风格和场景关系是否延续。

将已选图像风格落实到 design.md 和每次生成提示，统一全课的配色、质感、光照与角色比例；SVG 动态元素与图片视觉协调。白底双色是版面与标注的默认，不限制图片只能用双色或矢量风格。

生成提示交代图片的教学用途、主体与姿态、构图和文字留白、风格，以及需要透明背景或分离的部件。课程文字与标注由代码叠加，避免把整页课程和答案烘焙进插画。生成后实际查看图片，核对语义、肢体连接及叠加区域，将选定文件保存到作品目录并在 design.md 简记用途、来源工具、提示、使用的参考图或编辑源图及成品路径；临时地址、占位图不算素材交付。随后按下文要求嵌入图片数据，保证独立课程包可显示。

时间来自 timing.json。关键变化跟随相应台词。只有整句时间时，按句首、句末安排完整的教学状态，并明确这是句级同步。句内动作确需跟随具体措辞时，先取得实际短语边界，记录来源；不能用整句起点加任意秒数冒充对齐。转场、移动自身的持续时间可为视觉设计值，但不充当语音锚点。同一场景复用持续可见的对象，只动画化实际变化的元素；不要为每句台词替换整页或重播整块入场。即使实现采用状态快照，相邻状态中未变化的内容也须视觉连续。零时刻直接显示开场状态；场景进出与动作由同一条可寻址时间轴控制，来回跳转不积累旧状态。使用同步创建、暂停的 GSAP 时间轴，暴露为 `window.__timelines[名称]`。本版 HTML 适配器不接其他动画运行时。

标注与对象放入同一可见性和位置分组；确需独立出现的说明，在设计中指明当时可见的指向对象。一个重点转到另一个重点时，先安排旧内容退出或降为辅助，再启用新的主画面；依据内容选择替换、移动或缩放，不规定固定版式。

只制作课程内容。字幕、播放暂停、进度条、题目暂停与作答反馈由 `assets/lesson-player/` 的固定组件负责。不要在画面里另造播放器。为真实字幕留出空间，注册 contentHeight 为画面正文实际最下沿，播放器据此保留字幕区域；它不能修复正文内部互相遮挡。

## 打包与预览

```sh
node <skill>/scripts/package_course.mjs --script <group>/script-vN.json --timing <group>/audio-vN/timing.json --html <composition>/index.html --timeline <名称> --content-height <正文最下沿> --out <preview目录>
python3 <skill>/scripts/preview_server.py <preview目录> --port 4176
```

打包器核对脚本和音频摘要，从时间表登记片段、字幕和互动；拷贝固定播放器，内联作品目录中的本地脚本，复制配音。作品 HTML 的 CSS 必须内联；图像等资源须使用内嵌数据，不能在隔离的画面 iframe 中依赖相对资源路径。只打包自己制作且已检查的本地代码。题目 prompt 有多行时，首行为题意，后续行为展示句；选项和反馈保持联合脚本内容。

固定播放器使用输入中的宽高，控制层保持统一样式并按画布比例适配。画面必须按实际画布设计；内容高度不得超过画布。检查所选尺寸下字幕、互动题和拖动行为，不能静默改为默认尺寸。预览服务只监听本机并支持音频范围请求，让拖动后能从正确位置发声。用 HTTP 打开课程，不能把浏览器直接打开文件的结果当作可靠播放验证。

## 完成判断

按 HyperFrames 当前可用 CLI 进行结构与渲染检查。截图点从设计中的状态切换生成：查看切换前、中、后，并对照此刻台词判断学生应看哪里、旧内容是否仍争抢重点、标注是否有可见对象。连续播放同一场景的多句讲解，检查未变化内容是否反复闪动、跳位或入场；再看文字变换和人物动作的中间帧；再在完整播放器里检查首帧、字幕区域、前后拖动、回到零、题目触发、答题反馈和继续播放。修正实际可见的错误；不因无影响的代码组织建议无限返修，也不将抽样截图称为全程逐帧审查。

记录检查过的时间点和交互、发现及修正的问题、尚未验证的能力。文件可打开不等于课程验收通过。成功后记录 preview_ready，展示可直接播放的入口，并按 [本地成品交付](delivery.md) 整理课程包。有任务连接时按服务与交付文档同步材料和回传课程。
