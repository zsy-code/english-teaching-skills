# 联合课程脚本

从已确认的全文结构、记忆提纲和课程走向继续。台词、原文呈现、图解与回忆提示一起细化。每段写清“当前理解什么 → 用什么线索记住 → 学生尝试什么 → 怎样核对”，相邻环节可合并，不机械拆成四页。英文原文独立用 en，中文解释用 zh，制作说明不混入口播。

在 visual 中说明当前结构位置、原句何时出现和撤去、回忆时保留哪些线索、核对时恢复哪些原句；这些变化绑定对应 speech。回忆片段的 speech 不提前念出待回忆原句，先邀请学生暂停尝试，再在继续播放后核对。片段是否含选择题与是否安排回忆是两回事；复述和背诵练习不伪装成可评分题目。

主画面一次承担一个任务：总览时看大纲，精读时看当前原文和相关图解，回忆时只保留必要线索，核对时恢复对应原句。切换时收起上一任务的完整内容；定位提示可小幅保留。不将全文、译文、大纲和插画长期并排堆放，也不规定固定左右栏。让阅读顺序、对齐和留白清楚，字幕留在固定区域。

按元素是否需要形变或部件动作选择图片与可控图形，允许混用；在 visual 中说明素材与动画的关系、跨镜头需要保持一致的角色或场景。素材生成留到脚本确认后，按 [画面制作](animation.md) 使用参考图或图片编辑延续一致性。

只实现方案中确定的回忆练习与互动；若有选择题，题意明确、答案唯一。改变目标、范围、主线或互动安排须先回到方案确认。布局和动画细节在本阶段细化，脚本完成后必须单独等待用户确认。

HyperFrames 在脚本确认后实现画面；不得以实现方便为由改写已确认台词或教学范围。

## 一份源文件，一份自动生成的阅读版

写 groups/<组目录>/script-vN.json，字段如下。字段组织制作材料，不规定课程页面布局。

| 字段 | 内容 |
| --- | --- |
| schemaVersion | 固定 "0.2" |
| groupId、version、planVersion | 本地组编号、本脚本正整数版本、批准方案正整数版本 |
| planSha256 | 所读方案原文件的 SHA-256；用程序计算 |
| title、videoSize | 本课标题、实际 width/height |
| visualDirection | 本课的情境与整体图文组织方式，一段简短说明 |
| beats | 按播放顺序排列的讲解片段，见下表 |
| coverage | 已确认的关键教学点如何落实到实际台词：每项为 point 和 speechIds；编写时对照原方案，不新增教学范围 |
| reservedReadAlong | 可选数组，仅在确有跟读需求时记录 afterBeatId 与 text，默认空数组 |

每个 beat 使用：

| 字段 | 内容 |
| --- | --- |
| id、purpose | 稳定的片段编号、本段帮助学生理解什么 |
| speech | 有序数组，每项为 id、lang（zh/en）、text；id 在整课唯一，text 为实际台词 |
| visual | layout（布局关系）、initialState（刚进入时可见的内容）、cues（每项为 speechId、at=start/end、action，描述对应变化）、handoff（如何接到下一段；末段如何收束） |
| interaction | 没有则 null。有则是本段台词结束后触发的选择题：type="choice"、prompt、options（每项 id/text）、answerId、feedback（correct/incorrect，给出解释和纠错依据）。脚本阶段描述数据，动画打包阶段接入固定交互组件 |

语音后的题目反馈与普通 speech 分开存放，避免默认播放时泄露答案。coverage 引用本课真实台词 id；它是供核对的索引，不是凭填写“已覆盖”就自动通过的证明。标题和画面说明只写课程内容；测试来源、工具读取过程和能力声明留在批次记录，不混入学生台词或课程设计。

用随 skill 提供的工具检查并生成阅读版：

    python3 <skill目录>/scripts/script_tool.py <组目录>/script-vN.json --batch <批次目录>/batch.json --group <本地组编号>

工具检查批准版本、方案摘要、编号引用、互动答案、基本结构，并生成同名 .md。不得跳过失败项或手改阅读版掩盖源数据问题。主会话核对输入尺寸是否正确，工具不负责自行猜测不同来源 input.json 的格式。

之后做一次连贯阅读：核对是否有真实的“撤去原文 → 学生尝试 → 原文核对”，最终提纲是否能找回全文主要部分，以及复述与背诵要求是否区分。按学生的播放顺序读台词并对应画面，判断开场是否给出方向、转折是否有来由、解释是否具体、作答是否打断理解；连读整课中承担回顾作用的段落，判断每次重现是否有新的教学作用；功能相同的重复归并，不靠换布局掩盖重复台词。再对照确认方案核对关键内容与答案是否提前泄露。coverage 用来查缺漏，不用来扩充课程。结构检查不证明教学正确、台词自然或画面好看。发现明确问题就修正，不增加无目的审查轮次；需要改变方案范围时返回用户确认。

主会话保存脚本版本、SHA-256 和完整阅读版链接，标记 awaiting_confirmation、pendingStage=script，向用户展示逐句台词、对应画面与互动并等待确认。不得在等待期间制作音频或动画。确认后记录 scriptApproval，标为 script_ready，再接续[配音与实测时间](audio-timing.md)。脚本不是已渲染画面，不能声称完成逐帧检查或实际配音同步。
