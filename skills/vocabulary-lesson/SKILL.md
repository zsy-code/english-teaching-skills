# 词汇教学课程

## 使用前

每次调用先执行 [检查与自动更新](references/update.md)，更新后重新读取当前规则。新任务按最新规则制作，已有材料和用户确认不因更新而失效。

## 当前范围

本版为 0.11：读取任务 → 拟定教学目标、完整课程走向、主要场景与基础台词 → 用户逐组确认 → 细化逐句台词、动画、素材与互动 → 用户逐组确认脚本 → 配音与实测时间表 → HyperFrames 画面实现 → 固定播放器预览 → 本地成品交付。
本版交付可独立预览的课程 ZIP 与当前教学材料。支持任务接口提供的 TTS、进度与材料同步、课程包上传。没有连接信息时按本地方式执行。

## 接收任务

读取 [任务输入](references/input.md)，保留用户原始要求、分组与来源版本。既支持自然语言，也支持任务附件，不要求用户填写程序字段或预先写方案。
核对词汇、学生情况和参考资料是否足以决定教学内容。只询问影响当前方案的缺失或冲突；普通假设写进方案供确认。生产工具暂不可用不阻碍独立的方案编写。

先读取 [所需服务与任务连接](references/services.md)，分离连接凭据并检查已提供能力。缺少当前阶段所需服务时提示补充，或使用环境中已有且获准的替代方式；按该文档同步实际进度。

## 编写方案

读取 [教学方案](references/teaching-plan.md) 和 [批次与确认](references/batch.md)。单组与多组使用同一套材料保存、版本和确认规则。每组对应一条课程，一份连贯的 Markdown 方案。分组标签是待核实的建议，不是教学事实。
单组直接完成；多组由主会话协调子 agent。每个子 agent 只负责分配到的组，保留其上下文以便修改。主会话汇总材料和所有待回复事项。

## 用户确认

展示每组的方案链接、当前版本、状态及待回复问题。明确请用户按组确认或提出修改，然后结束当前轮等待回复，不循环轮询等待人类。
启动任务不等于批准方案。只有用户明确确认了对应组的当前方案版本，才记录确认；局部确认不扩大到其他组。用户直接要求改动时先更新受影响方案，除非用户明确授权该修改后的版本，否则不推断它已获确认。

## 方案确认后

读取 [联合课程脚本](references/course-script.md)，由同一组执行者接续已确认的课程走向和基础台词，细化逐句表达、画面变化、素材与互动。已有明确且仍有效的确认可以接续，不重复要求用户确认。
改变教学目标、范围、核心场景、主要推进顺序或互动安排时，先回到方案确认；其他细化写入逐句脚本，交用户第二次确认。
保存联合脚本，运行校验与阅读版生成工具，核对台词、画面与互动的对应关系。展示完整逐句脚本阅读版、版本和待回复事项，然后结束当前轮等待用户确认。方案获批不等于脚本获批；未确认脚本前不得调用 TTS、生成图片、制作动画或打包。

## 脚本确认后

按 [批次与确认](references/batch.md) 记录对应脚本版本、文件 SHA-256 和用户回复。仅确认记录与当前脚本匹配的组可以继续。没有用户要求的暂停点时，继续读取 [配音与实测时间](references/audio-timing.md)，复用用户指定的服务生成音频与时间表。随后读取 [动画制作与播放器](references/animation.md)，调用 HyperFrames 制作课程画面，接入固定播放器并实际试播。保存材料及检查结果，区分可预览与用户验收。用户未要求暂停时，继续读取 [成品交付与回传](references/delivery.md)，导出并在独立目录验证课程包。

## 内置课程规范

- 尺寸采用任务中的宽高；未指定时 1920 × 1200。尺寸是后续制作输入，不是编写方案的阻塞项；明确但不合法的值需要指出。
- 默认互动 HTML、中文讲解、英文单词和例句朗读、白底双色图解。具体页面由 AI 根据教学内容设计；播放器和字幕使用固定组件。
- 画面可混用生成插画、图解与动画，不限于 SVG。静态图片优先使用当前 agent 框架内可调用的图片生成能力；框架不支持时再用已配置的图像服务，详见服务与动画制作说明。
- 不在教学方案阶段估算时长，也不默认限定重点词数量或用时长压缩教学内容。
- 跟读组件目前仅预留，可记录需求，不承诺录音或评分功能已经存在。
- 明确的用户要求优先于默认值；不支持的能力如实说明。配音等服务配置由后续工具读取，不放入教学提示词。
