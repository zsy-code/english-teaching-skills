# 题目讲解脚本

读取已确认试卷与解析，保持题干、选项、答案及版本一致。答案解析是依据，不是直接朗读的脚本。只补足推导所需的解释；前面已讲清的内容不再换句话提醒，也不预设学生犯错后反复告诫。按学生理解所需的步骤展开，不限定段数、句数或时长。

## 选择与填空

每题一条视频，多空同题依次解释。先明确题意，再说明题内线索、适用知识及其如何得到答案。词汇题讲清决定选择的词义、搭配或语境关系，并解释有价值的干扰项；不只报词义和答案。语法题讲清决定形式的条件；涉及动词形式时，交代语境与时态，再结合主语等条件确定形式，不能只凭人称得出答案。没有充分时间线索时如实说明语境判断，不把普通短语说成唯一的时态标志。

填空逐空推导，已完成答案保留，最后放回完整句子理解。选择题收束到答案及关键依据，不再加题，也不扩展无关语法课。

## 阅读

一篇文章及其全部小题组成一条视频。开场用标题简短引入，随后按原文顺序带读全文，同步突出当前句子；在自然段或意群结束后解释影响理解的词句，帮助串起意思，不机械逐句翻译。全文读完，再结合刚读过的内容整理文章大纲及前后关系；不能在学生读原文前先灌输总结，也不提前公布各题答案。

随后逐题：读懂问题要找什么，带着问题回到文章，定位证据，解释证据如何支持选项，并说明必要的干扰项。题目变化时保留文章上下文，切换当前焦点。最后简短收束文章与已解问题。

联合脚本标记“通读文章”“文章大纲”“第 N 题”等有名称的章节及首个 beatId；配音完成后以真实时间登记到固定播放器的进度条，可直接定位章节。章节导航不是答题暂停点，不在课程画面里新增按钮。

## 台词与画面

实际台词逐句写全，英文问题或关键句朗读单列；题干有空时，不在分析前补读答案。用自然口语解释，不朗读字段和解析标题。

口播用于推理的词义、语法条件、原文证据都要有对应画面：词义贴近相应单词，语法条件对应题内依据，阅读证据与问题建立联系。标注随对应台词出现，不能仅靠字幕承载解释。每个 cue 写明实际显示的文字、指向对象与出现时机，避免“标出线索”等空泛指令。

按题意组织原题、上下文和标注，预留解释空间；答案随推理揭示。静态情境图或动画仅在有助理解时使用，不强加故事。播放器保持独立。
